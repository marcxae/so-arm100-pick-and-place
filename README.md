# so-arm100-pick-and-place
Autonomous pick-and-place system for the SO-ARM100 robotic arm, guided by computer vision. Distributed architecture: ROS 2 Jazzy vision pipeline (HSV segmentation + solvePnP camera-robot calibration) on a PC, with embedded actuator control over UART on a Raspberry Pi Zero 2 W. Bachelor's Thesis - Robotics Engineering, Universitat Jaume I (UJI).
